# Lean pedal setup — 4 November 2026

## Delivered behavior

Owner-directed scope reduction: the runnable application contains controller selection, optional clutch, one setup button and the resulting pedal test. HID inventory, axis monitor, signal/noise analysis, sweeps and JSON export have been removed from the window and excluded from the application build. Their earlier algorithms/tests remain in the repository for historical evidence and rollback, not as active UI or shipped application features. NoiseRun was moved out of the compiled calibration model into the excluded diagnostics file; its algorithm was not rewritten. No new dependency or framework.

PedalSetup in the existing CalibrationModels.cs owns exactly one current role. It runs one validated press/release to identify that role's axis, then three presses to calibrate the same axis. Only then does it store the result and advance to throttle, then optional clutch. Identification results are never presented as completed calibration. The existing GuidedCalibration engine now accepts identification mode and a locked axis; default three-press behavior remains available to earlier tests. Every heading and gauge label comes from CurrentPedal. The final display uses each result's own Mapping.Axis. No axis names are prescribed to the user and no swap repair exists.

The window uses the existing WinMM reader and whole-sample range checks. Failed reads, invalid bounds/values or polling interruptions invalidate the setup, discard results and clear instruments. Refresh and deliberate controller selection after interruption are required. Changing controller/clutch resets setup. Timing uses Stopwatch. No controller/firmware/driver/Windows setting writes occur; calibration is an application preview, not persistent device calibration.

## Run

Extract the complete ZIP into a new folder and run MecaCalibrationWizard.exe. Select the controller, enable clutch only if installed, release all pedals and click Start setup. Follow the named prompt: identify brake once, calibrate brake three times; identify/calibrate throttle; optionally identify/calibrate clutch. Keep pedals released during each short baseline. In the final Pedal test, press one pedal at a time and check its name. Refresh restarts after an interruption. Closing the app loses this preview; there is no profile persistence or hardware write. Previous packages remain unchanged for rollback.
